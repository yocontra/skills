# Onboarding plan template

Title:

```
Onboarding plan — <New Hire Full Name>
```

The plan covers the first 90 days. The doc is shared with the new
hire (with edit access) so they can annotate their own progress.

## Per-section rules

The writing rules (observable goals, "why this person" reasons,
≤5 reading list, first-task scope, honest pace framing) live in
[house-style.md](house-style.md). Apply them while filling in the
template above.

A few template-specific reminders:

- **Mentor section:** include only if the manager assigned a mentor
  distinct from the buddy. Otherwise omit entirely.
- **Notes (new hire's space):** always present, always empty when
  shared. The new hire owns it.
- **Resources:** ≤5 links. Skip the obvious (HR system, SSO)
  — those auto-onboard. Include team-specific links the new hire
  wouldn't easily find.
